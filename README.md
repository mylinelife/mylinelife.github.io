# MyLineLife — mylinelife.ru

**MyLineLife** — справочник по Таро, рунам и хиромантии на русском языке и Telegram-бот для гадания по ладони по фото.

- Сайт: [mylinelife.ru](https://mylinelife.ru)
- Telegram-бот: [@mylinelife_bot](https://t.me/mylinelife_bot)
- Канал с картой и руной дня: [@mylinelife_daily](https://t.me/mylinelife_daily)
- ВКонтакте: [vk.ru/mylinelife_daily](https://vk.ru/mylinelife_daily)
- Pinterest: [mylinelife_bot](https://ru.pinterest.com/mylinelife_bot/)

## Разделы сайта

- [Значения 78 карт Таро](https://mylinelife.ru/taro/) · [Таро да или нет](https://mylinelife.ru/taro/da-ili-net/) · [Карта дня](https://mylinelife.ru/taro/karta-dnya/)
- [24 руны Старшего Футарка](https://mylinelife.ru/runy/) · [Руна дня](https://mylinelife.ru/runy/runa-dnya/)
- [Линии на руке и их значение](https://mylinelife.ru/hiromantiya/) · [Знаки на ладони](https://mylinelife.ru/hiromantiya/znaki-na-ladoni/)

Материалы развлекательные, 18+.

## Для разработчиков

Страницы генерируются скриптом: `python3 _src/build.py` (данные — в `_src/data_*.py`, стили — `assets/style.css`). Папка `_src` не публикуется GitHub Pages.
